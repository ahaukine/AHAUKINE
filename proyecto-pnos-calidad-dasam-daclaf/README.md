## Cómo montar el Project (5 pasos)
1. En la cuenta corporativa de Calidad, crear el Project `PNOs Calidad`.
2. Pegar `00_INSTRUCCIONES_PROYECTO.md` en *Project instructions*.
3. Subir como conocimiento: `CONTEXTO.md`, `MEMORY.md`, `01_Diseno_Sistema_PNO.md` y el inventario.
4. Subir el inventario priorizado y los PNOs vigentes al *sandbox* (carpeta local o de nube), sin sobrescribir versiones anteriores.
5. Cada sesión: actualizar `MEMORY.md`, `02_Inventario_PNO.csv` y `BITACORA.md`.
