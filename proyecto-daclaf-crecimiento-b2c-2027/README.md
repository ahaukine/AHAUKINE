## Cómo montar el Project (5 pasos)

1. Crear un Claude Project llamado `DACLAF · Crecimiento B2C 2027`.
2. Pegar `00_INSTRUCCIONES_PROYECTO.md` en *Project instructions*.
3. Subir como *Project knowledge*: `CONTEXTO.md`, `MEMORY.md`, `01_Diseno_Sistema_Multi-IA.md` y `02_Contrato_de_Intercambio/*`.
4. Subir además el catálogo y las bases de datos internas **solo en la cuenta corporativa** (ver clasificación de datos en `01_Diseno...` §3).
5. Cada sesión: actualizar `MEMORY.md` y agregar entrada a `BITACORA.md`.
